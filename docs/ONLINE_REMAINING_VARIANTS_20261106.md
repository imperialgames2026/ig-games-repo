# Remaining authored practice variants

Connects 22 more November 2 authored variants to the existing authenticated private practice adapter: NLHE and Omaha PLO at 2/4/6/7/8/9 seats; Classic, Crazy and Lazy Pineapple; Five-card Stud, Five-card Draw and 2–7 Triple Draw at six seats; plus standalone Blackjack, American Roulette, Craps and Baccarat. These are separate private practice rooms; existing main-site poker/casino routes are not replaced. Poker table chips and casino counters stay inside the private room state and never touch wallets, payments, prize claims or ledgers.

Server rules, not client values, determine legal turns, pot-limit raises, side pots, draw/discard choices, dice, decks and outcomes. The service continues to require confirmed canonical accounts, invitation and occupied human seats; testers are read-only. Private projections omit deck, burn, muck and discard piles, folded cards and opponents' hidden cards. Stud exposes only public upcards; Blackjack hides the dealer hole card until settlement. CSPRNG draws and durable actor/request receipts preserve retry behavior. Client authority fields remain forbidden; casino amount values accept only the bounded, game-specific practice amounts and the rules enforce denominations/balance. Roulette validates actual betting spot membership rather than inherited object properties.

Hosted roulette displays imaginary practice chips and makes no exchange-rate request. It offers no currency selection, wallet conversion or financial action. Original table GLBs are copied from the latest authored handoff and recorded in the shared asset provenance inventory.

Progressive Draw (`progressive5`) remains unavailable. In the authored rules, successive unopened deals increase the opening requirement through royal flush; a full-match test exhausted 6,000 actions without reaching a terminal state. This requires a gameplay decision about the opening progression/redeal boundary before activation. No substitute rule was silently introduced.

Hosted paired-account acceptance remains blocked by missing test access: no authorized saved practice credentials or signed-in browser sessions were found, and the connected tools supply public client keys but no standard Auth-admin account provisioning operation. No existing person's password, Auth record, confirmation or role was changed. Disposable local users use the real GoTrue password flow and actual PostgREST/RLS.

Backend rollout: migration `20261106043013_remaining_authored_practice_games.sql` and JWT-protected function version 3 are installed. The existing raw-table/RPC grants are preserved. Frontend promotion follows CI. Local acceptance passed all 38 desktop/mobile screens, nine-account private poker seating/move, Blackjack dealer privacy and actions, roulette chip/spin actions and zero currency-quote requests. Canonical wallet rows were byte-identical before and after the full browser journey. The full regression run passed 261 application checks and 37 replay checks; additional focused folded-card, side-pot/Omaha and roulette spot tests passed.

Bowling is explicitly parked under Nathan’s instruction. It is absent from the main authored practice registry and hosted whitelist; a negative create test requires rejection. No Bowling asset or route is introduced by this release.
