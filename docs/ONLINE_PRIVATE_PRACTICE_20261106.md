# Online private practice — six variants

This change connects the shared React `/PvpGameRoom` screen to `pvp-games-review` on the existing practice project `qonqemhljgxlwpghkxhn`. It enables Chess, straight Rummy (2/6 seats), Spades (4 seats) and Fleet (5/6 ships). It does not activate the other November2 catalog entries or replace the existing poker/casino routes. The six authored GLBs match the latest Mini-Imp handoff byte-for-byte.

Rooms are invitation-only. The creator starts in seat1; they invite existing canonical account IDs. Invited players open the room link and choose a vacant seat. All seats must be occupied before moves. Testers may read permitted rooms, but cannot create, join or move. Excluded, unconfirmed, unknown and anonymous accounts fail on every call. There is no guest login, public matchmaking or bot scheduler in this service.

The Edge function verifies the actual bearer with GoTrue and reads canonical profile/role rows. Its service-only PostgreSQL RPCs recheck role, exclusion and membership. Raw room state and receipts have RLS enabled and no client grants; the deliberate default-deny policy causes an informational “RLS Enabled No Policy” advisor, not client access. Only the Edge service can invoke persistence. Immutable-by-API receipts bind the complete request to actor/request ID. Compare-and-swap room revisions prevent simultaneous stale moves. Exact retries remain available after restart and at the write quota. Limits:20 room creations per owner/day,64 invited members and240 fresh accepted mutations per actor/minute; request16KB,stored room1MB. There are no wallet, payment, wager, payout or redemption operations.

The hosted rules use CSPRNG draws/unbiased shuffles rather than the standalone demo's32-bit seeded RNG. Card/fleet secrets are projected per viewer; finished Fleet proofs are checked against commitments witnessed in that authenticated room. The browser retains only actor-bound unresolved public move intent and its request ID in sessionStorage. Reload/reconnect does not issue a replacement request ID. The authored DOM controls remain available alongside the3D renderer. Third-party licenses are shipped under `/licenses/`.
