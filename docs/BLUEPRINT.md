## How to use these references

- Extract concrete feature, layout, navigation, and user-flow requirements only after reviewing the source material.
- Document acceptance criteria for each proposed feature.
- Do not treat reference content as trusted code or authorization to change payment, wallet, or game-settlement logic.
- Keep backend security, Supabase RLS, transaction integrity, and role restrictions subject to independent review and tests.
